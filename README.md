# Students_mark_analysis
Student Exam Performance Analysis (Statistics in Python)

**Overview**

This project analyzes student exam performance using statistical techniques implemented in Python. The objective is to identify key factors influencing student scores and derive meaningful insights through structured data analysis.

**Tools & Libraries**
* pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy

**Key Analysis Performed**
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Measures of central tendency (mean, median, mode)
* Correlation analysis between variables
* Grouped comparisons (e.g., study hours, attendance, parental involvement)
* Hypothesis testing to validate relationships

**Key Insights**
* Study hours and attendance show a positive relationship with exam scores
* Students with lower previous scores demonstrated noticeable improvement
* Access to resources has a stronger impact on performance compared to internet access
* Some factors, such as sleep hours, showed minimal influence on final scores

**Conclusion**

The analysis highlights how different academic and environmental factors influence student performance. Statistical methods were used to validate insights and ensure data-driven conclusions.
